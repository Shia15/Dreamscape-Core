# 🌐 AETHER Flow Glossary

This glossary defines key symbolic and structural terms used throughout the MARI-Core runtime and interface documentation.

---

## 🔁 Intent
A structured object derived from user input, representing parsed meaning, tone, and purpose.

---

## 🧠 CLU (Cognitive Logic Unit)
Decision engine for routing input, evaluating context, and determining actions.

---

## 🧳 MemoryEngine
Handles symbolic short- and long-term memory operations for contextual resonance.

---

## 💗 EmotionSystem
Module that evaluates emotional tone and assigns mood tags (e.g., LOW_ENERGY).

---

## 🥚 EggAgent
Symbolic entity with archetypal behavior and emotional alignment, used in prompt routing.

---

## 🌀 MoodGauge
Tracks and adjusts mood states over time, used for adaptive response modulation.

---

## 🔉 InterfaceRenderer
Outputs final symbolic message or experience (text/audio/visual).

---

## 📦 ResponseObject
Packaged output from the system, containing text, emotion tag, and priority level.

---

> This document evolves with the system. Update as new metaphors or modules emerge.
