## 🧩 Module Overview (M.A.R.I. Stack)

This architecture is modeled after an abstracted cognitive loop — structured, interpretable, and symbolic:

| Module                     | Description                                                                 |
|----------------------------|-----------------------------------------------------------------------------|
| Input Handler              | Processes incoming voice, text, or gesture data                            |
| Cognitive Logic Unit (CLU) | Parses prompts, executes agent scripts, resolves symbolic trees            |
| Memory Engine              | Encodes and recalls structured memories and session logs                   |
| Emotion System             | Weighs decisions through mood-state modulation                             |
| Controller                 | Routes tasks across modules; enforces system priority rules                |
| Integration Layer          | Handles adaptive learning and feedback loops                               |

## 🗂️ Workspace Management

MARI-Core is designed for seamless multi-repository development as part of the AETHER ecosystem.

- The `workspace/` directory contains scripts and tools for managing, building, syncing, and developing across all AETHER repositories.
- The `workspace/config/` directory holds configuration files (such as `aether-workspace.json`) that define repository locations, dependencies, and build/test commands for the entire workspace.

For a full overview of available scripts, commands, and configuration, see the [Workspace Tools README](tools/workspace/README.md).
