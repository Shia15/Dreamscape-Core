# AETHER Workspace Tools

Drop this folder into the root of `mari-core` (or your chosen workspace root).

Scripts map (use via npm scripts in package.json):
- `node tools/workspace/clone-all.js`
- `node tools/workspace/install-all.js`
- `node tools/workspace/sync-all.js`
- `node tools/workspace/build-all.js`
- `node tools/workspace/test-all.js`
- `node tools/workspace/status-all.js`
- `node tools/workspace/dev-runner.js`
- `node tools/workspace/health-check.js`
