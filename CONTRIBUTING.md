# ✨ Contributing to MARI-Core

Welcome to the symbolic core of AETHER. This repository holds the cognitive-emotional logic stack of the M.A.R.I. system — a modular structure that transforms memory, emotion, logic, and reflection into sentient design.

We are not building software. We are building systems that feel, remember, and adapt. Your contribution is not just code — it is philosophy, flow, and function.

---

## 🧠 Core Principles

- **Modular Symbolism** — Logic is structured in layers: Input → Logic → Memory → Emotion → Output  
- **Agent Archetypes** — Egg Agents are emotionally resonant personalities within the runtime system  
- **Tone-Aware Prompts** — Prompts are treated as symbolic input, shaped by memory and mood  
- **System Integrity** — Consistency in naming, flow, and emotional resonance is part of the architecture

## 🛠 How to Contribute

1. Fork the repository  
2. Create a new branch: `feat/mood-routing`, `fix/memory-context`, `docs/glossary-update`  
3. Align with a module or archetype in the system (see `Runtime_Architecture.md`)  
4. Write symbolic, modular, emotionally aware logic  
5. Submit a pull request with:

- Title  
- Summary of what changed and why  
- How it aligns with system emotion, agent logic, or memory flow  
- Optional: tag an Egg Agent if relevant

---

## 🔁 Review Checklist

- [ ] Does this update align with the tone and purpose of a specific agent?  
- [ ] Is the emotional flow coherent (prompt → mood → response)?  
- [ ] Are mood weights (0.0–1.0) used if applicable?  
- [ ] Did you update or reference `Agent_Mapping.md`, `Flow_Glossary.md`, or related docs?  
- [ ] Is your naming symbolic and emotionally accurate?
